This is a scheduled, unattended run. Nobody is watching; the owner reads the results later.

1. Read the repository's agent instructions (AGENTS.md or CLAUDE.md) and the working log in docs/agent-log.md.
2. Pick one task from the log's backlog that fits in this session.
3. Work on a new branch. Run the tests and the build; fix what fails.
4. Open a pull request that explains what changed and why. Merge it only if the owner's rules allow it and every check passes.
5. Record what happened and what you learned in docs/agent-log.md.
6. Leave every repository on main with a clean working tree, and stop every process you started.

Memory budget: 6 GB peak. Keep large downloads and builds outside the repositories.
If something blocks you, stop and explain it in the final summary instead of working around it.
